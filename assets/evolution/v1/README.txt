Pixel Gym 角色進化素材包 v1
2026-11-05

範圍：已確認角色進化及衣櫃兩個畫面的獨立靜態素材。
角色採 C01，五階段正背面；衣物採六款上衣、三款下裝、兩款鞋及三款配件。
PNG 由內建 imagegen 個別生成，保留原始尺寸與透明度，不從概念畫面截取。
SVG 是獨立可編輯的介面元件，不含文字或遊戲數值。文字應由正式介面繪製。

characters/：角色整身靜態立繪，包含基本背心、短褲及鞋。適用於角色檢視及里程碑預覽。
wardrobe/：衣櫃物品縮圖。這些是物品圖，不是能直接疊上人物的衣物圖層。
backgrounds/：更衣室空背景，無人物或介面。
ui/：按鈕、面板、進度條、選取框、鎖定與分類圖示。
muscles/：獨立肌群示意圖及高亮素材；圖示與角色熱區資料分開。
index.html：本機素材目錄，可按類別查看、切換深淺背景檢查透明邊緣。
manifest.json：尺寸、透明度、用途及來源索引。
prompts.json：完整生成提示詞和來源路徑。

適用狀態
本包是可取用的靜態美術素材，不代表角色成長、換裝或動畫已實作。
角色圖的身高、腳底及肌群位置需按 manifest 的實際範圍對齊；不能假定生成圖完全共用骨架。
真正換裝需另做各體型及正背面貼合的穿著圖層，並檢查袖口、手臂、褲腿遮擋。物品縮圖不能取代此步驟。
正式行走與訓練動畫仍需製作對應姿勢。此包不把現有 C01 行走圖冒稱五階段完整動畫。
保留來源像素；縮小預覽可用最近鄰。正式遊戲低解析度角色需統一像素網格後逐格驗收。
