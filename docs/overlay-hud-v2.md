# 全畫面浮動介面原型

2026-11-04。使用者已確認全畫面浮動介面方向，現已套用到可玩單人版本。

參考圖：`../assets/concepts/gym-overlay-hud-v2.png`。使用內建 imagegen，以 `gym-main-screen-v1.png` 為美術參考生成。

- 健身室延伸至整個畫面，取消固定右側欄及整條頁首、頁尾。
- 左上角色狀態；右上訓練券、好友與可收合目標。
- 正在使用的器材旁顯示組數與動作回饋，力度條浮在器材附近。
- 訓練時仍能看見其他角色活動，不另開遮罩訓練頁。
- 右下為快捷按鈕；左下為聊天提示。保留中央行走及角色操作的可見空間。

圖中等級、好友人數與進度是視覺示例。可玩版本顯示實際成長與單人狀態，不虛構在線玩家或等級。

## 已實作行為

全視窗 Canvas 保持比例填滿畫面；窄屏跟隨角色，底部木地板延伸供鏡頭留出操作空間。點選地面透過同一鏡頭座標轉換，仍遵守器材碰撞。

左上為角色狀態；右上為券、單人狀態與可收合目標；右下是課表、角色、好友說明與表情。課表按需要展開，選擇訓練後收起。表情會短暫出現在角色頭上。

準備、訓練、暫停與結算均為無遮罩的場景內浮動區塊。訓練時主角在實際器材上顯示動作，操作條只顯示節奏／力度，不重畫另一間訓練場景。下方空間不夠時，桌面版自動將區塊移到器材側面。

Esc 暫停，保留該節進度；離開不扣券。訓練中其他選單停用，避免輸入衝突；目標暫時收合，結束後恢復原狀。正式／練習規則、每週貢獻及原有存檔鍵保持相容。

仍屬單人原型，沒有多人連線。臥推為簡化分層動作，尚未完成正式像素動畫製作。
