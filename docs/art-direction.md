## 視覺方向

溫暖、有人生活的日式街角健身室。深色描邊、細緻像素感、成年 Q 版角色，體型與姿勢自然。以主畫面的房間和 UI 為整體方向，角色表供服裝與髮型細節，物件表供器材和家具造型。

畫面採略俯視的正向三分之四 RPG 室內視角，不轉成菱形等角地圖。夜間窗外深藍，室內暖黃燈、蜂蜜木地板、青綠訓練墊、深灰金屬器材、珊瑚色飲品機和焦糖色沙發。

建議製作用色如下，為近似設計色票，並非圖片逐像素取樣：深藍 UI #192332、奶白文字 #FFF0D3、薄荷綠互動 #81E8BB、蜂蜜木 #D9954E、青綠墊 #467E79、珊瑚紅 #CF6C68、深灰器材 #494653。

避免照片風、光滑3D、霓虹賽博風、過度性感化造型、寫實健美比例，以及以模糊插值放大像素。繁體中文介面須清楚易讀，不能為像素字體犧牲辨識度。

## 場景層次與擺位

底圖保留牆壁、木地板、窗外商店街、窗框、固定燈具和右下入口，無 UI 和活動角色。它是重新生成的空場景，不是原畫面逐像素拆除物件的結果，因此不可假定座標完全一致。

預定分區：後方左側跑步機與划船機，後方右側深蹲架和啞鈴；中央臥推；前方左側平衡墊及儲物區；前方中央沙發茶几；右下入口保持通道暢通。

正式分層：背景建築 → 地墊與地面陰影 → 器材與角色按腳底深度排序 → 前景遮擋 → 燈光效果 → UI。入口牆及高器材須有遮擋處理；目前底圖將建築光影合併，實作時可能需要重繪分層。

## 正式素材製作要求

### 單人原型新增素材

`../assets/runtime/c01-walk-v1.png`：1086 × 1448、透明 PNG，3欄4列。各列依次為正面、左側、右側、背面；每列為站立與兩個踏步姿勢。以角色表 C01 為生成參考。程式在每個格內讀取透明邊界，保持腳底錨點；尚未重繪成統一64 × 96像素來源格。

`../src/room.mjs` 記錄物件圖集的人工檢視取用範圍，避開編號標籤。原型以 Canvas 個別繪製物件，不覆蓋原參考圖。現有六個可用設施是兩部 P01 跑步機，以及 P02 划船機、P03 深蹲架、P04 臥推和 P07 核心訓練墊；其他家具保持陳設用途。每個可用設施保留自己的名稱與接近位置。

`../src/exercise-art.mjs` 集中繪製五類 C01 訓練動作，依 `../src/session.mjs` 的動作進度更新姿勢：跑步交替踏步、臥推發力與回落、划船伸腿與拉回手柄、深蹲下降與起身、核心前臂支撐及重心傾斜。角色頭部沿用 C01 行走圖集，身體與可動器材以兩個世界像素為單位繪製色塊及描邊，保留灰背心、深藍短褲和白鞋。這是可互動的原型動作，尚未製成完整專用像素動作圖集。

使用中的臥推及深蹲器材需避開圖集內的固定槓鈴，再繪製隨動作移動的槓鈴；深蹲仍保留兩側架柱，槓鈴位於頭部下方的肩線。核心墊先作地面層繪製，使用中的角色另進入深度排序。兩部跑步機共用心肺玩法，但只在玩家選中的實體機器上繪製運動角色，使用背向鏡頭的踏步格，朝向機器螢幕。臥推頭部與上身縮短透視以貼合躺墊。五類動作已在瀏覽器檢視，桌面及手機實際截圖見 `screenshots/five-*-v3.jpg`；仍屬原型動畫，尚未獲使用者逐項確認。

本批是造型與構圖參考，不能聲稱已完成遊戲 sprite sheet、無縫 tile 或動畫。

正式製作先挑 C01 與 P01 驗證比例。建議角色來源格先以64 × 96像素試作，再依畫面可讀性定案；此尺寸不是現有圖集的裁切尺寸。採一致像素密度，整數倍最近鄰縮放，角色腳底中央為錨點，碰撞區取腳邊範圍。

角色需要四方向站立與行走，另有各器材動作、休息、招手和情緒。目前 C01 有四方向初版動畫與五類程式繪製訓練動作，其他角色仍只有造型表。正式版仍需統一像素密度的完整運動素材。器材需依角色接觸位置拆分前後遮擋及可動部件，例如槓鈴和跑步帶。

物件圖集已驗證有透明 alpha；仍包含標籤及局部陰影，正式使用要個別清理、去標籤並檢查透明邊緣。不得直接等分圖集後假定全部素材可用。角色表為不透明米白底，同樣需另製透明角色素材。

新圖使用 v2、v3 命名，不覆蓋 v1；新增或確認造型時同步更新本文件與索引。開始任何美術任務前實際打開圖片查看。
