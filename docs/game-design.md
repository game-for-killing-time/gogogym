# 像素健身室遊戲構思

## 已確認方向

遊戲讓約12人一起在網上的虛擬健身室做 gym。玩家操作角色運動，不要求現實運動記錄。風格為日式像素風，每日設有成長限額，鼓勵持續參與及輪換訓練部位。

以下具體數字和系統為目前設計提案，需試玩驗證；並非已完成的功能。

## 核心體驗

12個朋友共同經營街角小型健身室。每日用約10至15分鐘完成訓練，再自由留低陪朋友。期待來自角色變化、操作進步、熟悉會員及共同建設。

限額限制訓練收益，不限制上線時間、練習或社交。沒有因缺席而扣能力、清空努力或失去主要設施的懲罰。不販售額外成長額度。

## 每日流程

入場查看課表、朋友近況與恢復狀態；自選三節訓練或接受教練建議；完成小遊戲；結算能力、熟練度及每週進度；自由參與陪練、聊天、裝修、合照及合作活動。

每天3張訓練券，每節約2至3分鐘，每節包含準備、發力、控制和短休息。完成才扣券，未完成沒有獎勵。斷線應能恢復尚未結算的一節。每日固定時間補至3張，不累積。

同日正式訓練需選不同類別。昨天練過的類別今天仍可選，介面優先推薦未練類別。恢復狀態只是遊戲化課表提示，不代表真實健身處方。

| 類別 | 器材 | 操作構想 |
| --- | --- | --- |
| 推力 | 臥推 | 按住蓄力、適時放開、控制回落 |
| 拉力 | 划船機 | 交替輸入，保持拉動和回收節奏 |
| 腿部 | 深蹲架 | 控制下降深度與起身時機 |
| 核心 | 平衡墊 | 修正重心，應付方向變化 |
| 心肺 | 跑步機 | 跟隨節奏，選擇加速及回氣時機 |

設容易、標準和進階難度。基本收益接近，較難模式提供技巧評價與徽章。每種器材可輪換慢速控制、連續節奏等課題，避免全部變成狂按按鈕。

一週完成五類可獲全面訓練獎勵；參與四天可完成主要恆常獎勵。第五至七天仍正常成長，不放必需的獨家獎品。缺席後回來提供輕鬆課表，不重置已有進度。

示例課表：星期一推力、腿部、心肺；星期二拉力、核心、心肺；星期三推力、拉力、腿部；星期四自選補足目標。

## 角色成長

每節100點基本成長，加最多20點技巧獎勵。玩家完成即可獲得主要收益，高手仍有追求操作的空間。完成後不能重刷該節獎勵。

三層成長並行：

- 身體能力：五類各自累積，解鎖個人課程及動作表現。
- 器材熟練度：持續使用器材，解鎖動作動畫、個人紀錄及技巧稱號。
- 會員歷程：每週參與及合作活動，解鎖衣服、儲物櫃裝飾、入場動作和紀念相片。

角色由生硬動作變得穩定，可解鎖轉水樽、整理手套等動作。儲物櫃逐步有照片、貼紙和朋友留言。身形由玩家選擇，不強制隨能力變大隻。長線目標可選跑步專長、器材徽章收集或裝修。

## 12人共享健身室

一間房最多12名固定會員，隨時進出，不要求全員同時在線。熱門器材提供並行訓練位置，不以排隊作限制。

### 雙人拍檔

玩家邀請朋友同步訓練，一人控制動作、一人提供節奏提示，下一組交換。提供共同動畫、默契評分及雙人紀錄。各自持有訓練券就各自計正式收益；無券可陪練，但不提供額外能力點。邀請可拒絕，不扣獎勵。

### 三至四人循環站

每人選不同站，一局三輪，每輪約45秒。個人完成節奏目標為團隊儲氣，輪間共同選擇求穩或更難節奏，最後完成同步動作和合照。失誤只減少當輪分數，不令其他人立即失敗。

### 二至十二人團體課

例如三分鐘霓虹夜跑：每人處理自己的節奏，共同推進場景，由商店街跑至河邊。依實際人數調整目標；能力標準化，按完成率評分，新會員亦可加入。提供當週紀念品進度，重玩追紀錄，不無限產出資源。

### 非同步共同建設

例如一週解鎖天台。正式訓練提供工程進度，每人每週最多計12節。目標按週初活躍會員數固定，週中不加碼。達標後所有會員獲得設施；額外貢獻只有紀念裝飾。設施不加永久能力，避免大團體壟斷成長優勢。

留言板保留會員活動、表情及短留言。公共裝修、燈光和背景音樂由會員投票，私人儲物櫃自行裝飾。提供靜音、封鎖、舉報和房間管理。

## 美術與氣氛

日式街角健身室，夜晚暖燈、舊式儲物櫃、飲品機、鏡子及天台。畫面能看見多人同時運動、休息、飲水或擺姿勢。

入場門鈴與招手表情；練完坐凳抹汗，朋友可坐旁邊；飲品包裝可收集和贈送；合照掛在牆上。收藏和裝飾不提供能力優勢。

## 典型一晚

玩家入場見到三位朋友，完成划船機、拍檔深蹲及平衡訓練，解鎖新動作。三張券用完後，仍陪剛上線的朋友玩團體夜跑。天台建設達標，大家一起合照；離線會員翌日看到設施與照片。

## 首輪驗證

先驗證單人操作是否有趣、陪朋友是否自然發生、隔日是否有返回期待。需觀察訓練時間是否過長、三節是否足夠、輪換是否令人受束縛、高手與新手收益差距、缺席後返回意願，以及滿房時是否擁擠。
