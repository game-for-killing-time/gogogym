# 本機玩家檔案與五角色

本版不提供登入、Email 註冊或 Google 授權入口，亦不載入 Firebase SDK 或主動呼叫會員 API。既有 Firebase 帳戶及 D1 雲端角色資料保留，未刪除，也不自動匯入。

第一次填玩家暱稱、第一個角色名字及名牌配色。最多五個角色，能力、熟練度及每週進度獨立；每日三張券及同類每日一次則由整份玩家檔案共用。造型暫沿用 C01，不把名牌配色描述為完整換裝。

每次開啟會讀取本機檔案並顯示角色選擇，標示上次使用角色。選用入場後可自由活動。主畫面「角色選擇／備份」可編輯、切換、匯出或匯入。切換角色、修改身份或匯入前先離開房間，再以所選角色名字加入。進行訓練時不能切換角色。

新存檔鍵為 `gogogym.local-profile.v1`。建立首個角色時，把同來源的 `pixel-gym.player.v1` 舊訪客進度保留為首角色，原始舊鍵不刪除。其他網域或瀏覽器的資料無法自動讀取。

備份為有版本的 JSON，最多 2 MB。匯入先檢查格式、角色數、名稱、配色及進度範圍，再顯示角色摘要與確認覆蓋；取消不修改資料。確認時若另一分頁已更新檔案，要求重新確認。舊原始內容保存於 `.previous` 備份鍵；今天已用額度不因匯入較早備份恢復。格式錯誤或儲存失敗不宣稱保存成功。

同一來源的分頁透過 Web Locks 排隊寫入，結算會重新讀取最新存檔，依訓練收據避免重複收益。若另一分頁切換角色或玩家檔案，本頁中止訓練並返回選擇。需要支援 Web Locks 的新版瀏覽器與 HTTPS／localhost；不支援時顯示錯誤，不採用可能覆蓋資料的非鎖定寫入。

這是方便朋友試玩的本機檔案，不是帳戶認證。共用電腦可看到同一份檔案；清除網站資料可造成遺失，應自行匯出備份。本機資料可被玩家修改，不適用於可信排行榜。多人伺服器仍接收房間暱稱、動作及臨時連線資料；角色進度不傳到會員 API。
