# Pixel Gym 像素健身室

建立日期：2026-11-04。名稱暫定。

12名玩家共享一間日式像素健身室，操作角色進行虛擬運動。每日短時間訓練、角色成長與朋友互動共同構成遊戲核心。

## 專案資料

- [完整構思](docs/game-design.md)：保存討論中的玩法、美術、成長及社交構想。
- [第一版規格與開發次序](docs/prototype-plan.md)：將構思轉為可製作及驗收的範圍。
- [美術規範與素材索引](docs/art-direction.md)：主畫面、12人造型、空場景底圖與20組器材擺設。
- [多人連線 v1](docs/multiplayer-v1.md)：開房與邀請流程、同步規則、部署方式及目前限制。
- `AGENTS.md`：後續 AI 製作前必讀的專案及美術指引。
- `src/training.mjs`：每日額度、角色成長與共同建設規則。
- `src/session.mjs`：五類訓練的輸入、動作階段及評分。
- `src/room.mjs`：六個可用設施、點選判定、接近位置與尋路。
- `src/exercise-art.mjs`：C01 五類訓練的場景內動作繪製。
- `src/multiplayer.mjs`：加入房間、狀態同步、斷線重連及每分頁連線憑證。
- `multiplayer-server/handler.mjs`：本機及網上版本共用的房間服務。
- `online/`：Sites 網上部署專案，使用 D1 保存房間狀態。
- `tests/`：訓練規則、操作、器材可達路線及畫面座標的自動檢查。

## 目前進度

2026-11-05：新增 Firebase Email／密碼與 Google 登入介面、角色名字及會員配色、D1 雲端進度與伺服器訓練結算。由「角色 → 登入／建立角色」使用。設定、驗證範圍及限制見 [會員與雲端角色 v1](docs/accounts-v1.md)。訪客本機進度與雲端角色分開保存；多人連線暫沿用 HTTP 同步。

已完成五類訓練及最多12人同時在線的多人連線實作：同房玩家可互相看見移動、五款器材訓練姿勢、暫停狀態及表情。跑步機、臥推、划船機、深蹲架及核心訓練墊均可操作，保留四方向行走、點選尋路、碰撞、正式與練習模式、結算、每日額度及本機存檔。Sites 第1版已發布；本機雙瀏覽器、手機佈局，以及公開網站的雙用戶端加入與同步均已驗證。

介面採全畫面 overlay：角色、訓練券與可收合目標浮在場景上，右下快捷選單提供課表、角色、房間及表情。房間入口可建立房間、輸入房間碼、複製邀請連結及查看同房玩家。訓練操作、暫停和結算都在器材附近，沒有遮罩或獨立訓練畫面。

每日可從五類中選三類正式訓練，完成才扣券，同類每日只計一次。房間的兩部跑步機均可使用，共用心肺類別額度。自由練習不限次，不產生成長或建設點數。

多人容量由伺服器限制為12名同時在線玩家；原構思的固定會員制度尚未實作。目前六件器材各限一人使用，熱門器材的並行訓練位置留待後續擴充。所有玩家暫用 C01 角色，由暱稱和彩色名牌辨認。

房間狀態由伺服器共享；訓練能力、每日券、結算時間和建設貢獻仍由各自瀏覽器管理，不會跨裝置同步，也未具備伺服器驗證獎勵。帳戶、固定會員、音效、雙人合作及團體課尚未實作，天台仍只顯示個人進度。

## 開始試玩

網上版本：[Pixel Gym · 街角健身室](https://pixel-gym-club.magicforeveryone2026.chatgpt.site)。Sites 已確認第1版發布成功，朋友可使用此公開網址；發布後的瀏覽器驗證結果見下方紀錄。

在此資料夾以 Node.js 22.18 或更新版本執行 `npm start`，然後開啟 http://127.0.0.1:4178 。本機預覽使用內建 SQLite，無需安裝依賴；預設只監聽本機。不可直接雙擊 HTML，因為遊戲使用 JavaScript 模組及房間 API。本機網址不能提供給其他地方的朋友，跨地域試玩需使用已發布的網上網址。

開啟遊戲後，按「房間」，輸入暱稱並按「開新房間」。在房間面板複製邀請連結，朋友開啟後輸入自己的暱稱並加入；亦可在同一網站輸入6位房間碼。房間滿12人時會拒絕新的加入要求，離場後即可補入。

方向鍵或 WASD 移動；E 使用最近的器材；亦可點選地板、器材本身、名稱標籤或課表，自動走近器材。手機版提供方向按鈕。

| 設施／類別 | 操作 | 一節長度 |
| --- | --- | --- |
| 跑步機／心肺 | A / D 交替踏步，腳印到中線時輸入；按住 Shift 衝刺、放開回氣 | 25秒 |
| 臥推／推力 | 按住空白鍵發力，進入右方綠區時放開；回落到左方綠區再按一下接住 | 6次動作 |
| 划船機／拉力 | 按住空白鍵拉動手柄，進入綠區時放開；等手柄回收後再拉 | 6次動作 |
| 深蹲架／腿部 | 按住空白鍵慢慢下蹲，在綠區放開；角色穩定起身後再開始 | 6次動作 |
| 核心訓練墊／核心 | 按住 A / D 修正左右重心，保持在中央綠區；放開停止修正 | 25秒 |

場景內按鈕可完成相同操作。Esc 或浮動操作條的關閉按鈕可暫停、繼續或放棄；切換到背景會暫停並清除按住狀態。放棄或沒有足夠實際操作均不扣券、不給獎勵。划船和深蹲超時會進入回收或起身，不會卡在一次動作內。

進度保存於同一瀏覽器、同一網址的 localStorage。玩法說明中的「另開一份試玩進度」會備份當前進度並開始新檔。不同瀏覽器或網址不共用進度。中途重新整理不保存尚未完成的一節，也不扣券。
